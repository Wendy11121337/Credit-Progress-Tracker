畢業學分追蹤器 Credit Progress Tracker

關於本專案

本專案專為具備英文系與資料科學輔系雙重背景的學生設計，旨在建立一個客製化的畢業學分審查系統。透過視覺化介面，使用者可即時掌握剩餘學分缺口及尚未達成的畢業門檻，解決傳統校務系統資訊分散的痛點。

動機

身為即時面臨畢業的大學生，我發現校方系統存在兩大限制：
1. 直觀性不足：僅能顯示「已獲取學分」，缺乏對「剩餘目標」的動態追蹤與預測功能。
2. 分類容錯率低：校方系統在學分類別（如通識、選修）轉換時偶爾產生邏輯偏誤。
3. 即時性差：畢業學分進度只有在學期結束後才會更新，無法預測學分進度。

基於對行政流程優化的追求，我決定透過技術手段開發此專案，以確保畢業資格審核的精確性與即時性。。

主要功能

＊畢業門檻儀表板：於頂部區塊直觀呈現已完成與未完成的必要條件（如檢定、美育認證）。

＊必修進度檢核：採互動式勾選清單，動態追蹤必修課程完成度。

＊自定義課程擴充：支援使用者手動新增選修或輔系課程，並可自定義學分權重，確保系統彈性。

Credit Progress Tracker

About This Project

This project is designed for students with a dual background in English Literature and Data Science (Minor), this project is a customized graduation credit audit system. Through a visualized interface, users can track credit gaps and unmet graduation requirements in real-time, effectively addressing the fragmentation of information found in traditional university administrative systems.

Motivation

As a graduating senior, I found three major limitations in current campus systems:

Lack of Intuitiveness: They focus on "earned credits" rather than dynamic tracking and forecasting of "remaining targets."

Low Fault Tolerance in Categorization: Logic errors often occur when converting between credit categories (e.g., Minor Requirements vs. Electives).

Poor Timeliness: Progress only updates at the end of a semester, preventing proactive credit planning.

Driven by a passion for administrative process optimization, I developed this project to ensure the precision and immediacy of graduation eligibility audits.

Key Features

Graduation Requirement Dashboard: Provides a high-level visual summary of completed and pending requirements (e.g., proficiency exams, certifications) at the top of the interface.

Core Curriculum Audit: An interactive checklist that dynamically tracks the completion status of mandatory courses.

Custom Course Expansion: Allows users to manually add electives or minor-related courses with customizable credit weights, ensuring maximum system flexibility.

Tech Stack

Programming Languages

Python: Used as the core language for backend logic development and data processing.

JavaScript (ES6+): Handles frontend computational logic to achieve real-time credit summation and dynamic UI updates.

SQLite: A lightweight relational database ensuring data persistence and structured management of user records.

HTML5 / CSS3: Used for frontend architecture to create an intuitive UI/UX interactive experience.

Frameworks & Environments

Node.js: Serves as the server-side runtime environment to drive the overall project operations.

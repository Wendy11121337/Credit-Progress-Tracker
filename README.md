畢業學分追蹤器 Credit Progress Tracker

關於本專案：
本專案專為具備英文系與資料科學輔系雙重背景的學生設計，旨在建立一個客製化的畢業學分審查系統。透過視覺化介面，使用者可即時掌握剩餘學分缺口及尚未達成的畢業門檻，解決傳統校務系統資訊分散的痛點。

動機：
　　身為即時面臨畢業的大學生，我發現校方系統存在兩大限制：
　　1. 直觀性不足：僅能顯示「已獲取學分」，缺乏對「剩餘目標」的動態追蹤與預測功能。
　　2. 分類容錯率低：校方系統在學分類別（如通識、選修）轉換時偶爾產生邏輯偏誤。
　　3. 即時性差：畢業學分進度只有在學期結束後才會更新，無法預測學分進度。
　　基於對行政流程優化的追求，我決定透過技術手段開發此專案，以確保畢業資格審核的精確性與即時性。。

主要功能：
　　＊畢業門檻儀表板：於頂部區塊直觀呈現已完成與未完成的必要條件（如檢定、美育認證）。
　　＊必修進度檢核：採互動式勾選清單，動態追蹤必修課程完成度。
　　＊自定義課程擴充：支援使用者手動新增選修或輔系課程，並可自定義學分權重，確保系統彈性。

技術清單：

Language
*Python: 作為後端邏輯開發與資料處理的核心語言。
*(ES6+): 處理前端運算邏輯，實現學分加總的即時回饋與動態頁面更新。
*SQL (SQL Lite): 建立輕量化關係型資料庫，確保使用者資料的持久化儲存與結構化管理。
*HTML5 / CSS3: 建構網頁前端架構，打造符合直覺的 UI/UX 互動界面。

Framework
*Node.js: 作為伺服器端運行環境，驅動專案整體運作。
